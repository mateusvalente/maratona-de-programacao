Getting started

Welcome! Secure Bookmarks provides a password-protected bookmarks list in your favorite browser.

Below are a few tips on how to use Secure Bookmarks. It's pretty self-explanatory, so feel free to close this page and start bookmarking.

The Secure Bookmarks popup

Opening the Secure Bookmarks popup

Simply press the Secure Bookmarks icon in the top right corner to open Secure Bookmarks. You will be asked for your password every time you start a new Chrome session. If you've just installed Secure Bookmarks, you should already be logged in.

Working with bookmarks

Simply click the big 'New bookmark' button to bookmark the current page. Click the bookmark title to visit the bookmarked page. Note that Ctrl+click opens the page in a new tab. Each item features two buttons on the right-hand side, allowing you to manipulate it:

  • Edit the item title and/or url. Click again or press [enter] to save changes.
  • Delete item. Note that deleting a folder will also delete everything in it.

Using folders

Click the big 'New folder' button to create an empty folder. Items can be dragged into folders to keep things organized. Click a folder to collapse or expand it. Ctrl+click opens all bookmarks in the folder.

Toolbar items

You'll find two more icons in the top right corner of the Secure Bookmarks popup. These do the following:

  • Sign off to end your Secure Bookmarks session.
  • Visit the Secure Bookmarks settings page.

Frequently asked questions

How is my data stored?

Secure Bookmarks stores encrypted information locally, using Chrome's HTML5 localStorage implementation. No information whatsoever is sent over the internet. Encryption is performed in Javascript, using the Block TEA (xxtea) Tiny Encryption Algorithm. Please refer to this page for more information.

How do I use Secure Bookmarks in Incognito mode?

In Chrome, go to Tools >> Extensions (or type chrome://settings/extensions in the address bar) and expand the Secure Bookmarks entry. Tick the 'Allow in incognito' checkbox.

I forgot my password, how can I get to my data?

It's not possible to recover a lost password. You'll have to reset Secure Bookmarks to start anew, destroying all stored information.

I can't log in for some reason; can I still extract my data?

Yes, you can still use the Recovery page to extract your (encrypted) data. Save it to a text file, so you can restore the data later using the Backup page.

How do I change my password?

You can change your password on the Settings page.

Can I change the size of the popup window?

Yes, you control that from the Settings page. Also, you can change the font and icon size in the Secure Bookmarks popup by zooming in or out on this very page. Give it a try!

I love/hate this extension... what should I do?

You can leave a review in the Chrome Web Store. If you'd like to report a bug, or suggest new features, please use the Support page.

Backup & Restore

Use this page to export/import encrypted Secure Bookmarks data, or to retrieve your bookmarks in various formats.

Create Backup

Export your Secure Bookmarks data as a block of text to copy and store elsewhere. Data is encrypted using your current Secure Bookmarks password.

Restore Backup

Import a Secure Bookmarks backup by pasting the text here and supplying the associated password. Note that a backup can have a different password from your current Secure Bookmarks password; be sure to enter the backup password.

Restoring a backup will not remove or overwrite existing data.

View Data

Use the View Data button to obtain a list of your unencrypted bookmarks in various formats.

Reset

Forgot your password? Perform a full reset to destroy all information and pick a new password. Back up your data using the Recovery page if you want to attempt to restore it later.
