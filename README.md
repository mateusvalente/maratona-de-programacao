# Curso de Inverno de Programação

Material didático desenvolvido para os alunos do **Curso de Inverno de Programação** dos cursos de Tecnologia da Informação da **Uniube**.

O projeto apresenta uma trilha de aprendizagem em Python 3 formada por aulas teóricas, visualizações interativas, exercícios, códigos e resoluções comentadas. O objetivo é ajudar o estudante a compreender o raciocínio por trás dos algoritmos, e não apenas reproduzir respostas prontas.

**Professor responsável:** Professor Mestre Mateus de Sousa Valente  
**Instituição:** Uniube - Cursos de Tecnologia da Informação

## Acesso ao curso

O ponto de entrada do material é o [Portal do Curso de Inverno](index.html).

O portal funciona diretamente no navegador. Não é necessário instalar dependências ou iniciar um servidor local.

1. Abra o arquivo `index.html`.
2. Escolha um módulo de aprendizagem.
3. Comece pelas aulas teóricas.
4. Tente resolver os exercícios antes de consultar as resoluções.
5. Use as animações e os testes de mesa para acompanhar cada algoritmo.

## Organização do material

Cada módulo pode possuir uma organização própria, de acordo com o assunto trabalhado. De forma geral, o projeto utiliza:

- `aulas/`: páginas teóricas e experiências interativas.
- `exercicios/` ou `questoes/`: enunciados, PDFs e arquivos preparados para tentativa.
- `resolucoes/` ou `respostas/`: códigos Python validados e aulas que explicam as soluções.
- `assets/`: estilos, scripts, imagens e diagramas utilizados pelas páginas.
- `index.html`: página principal de cada módulo.

Os arquivos Python originais são mantidos separados das explicações. Nas páginas HTML, o mesmo algoritmo pode aparecer comentado e relacionado passo a passo com o problema.

## Metodologia sugerida

1. **Compreender:** identifique entradas, saídas, restrições e exemplos.
2. **Planejar:** descreva o algoritmo antes de começar a programar.
3. **Implementar:** escreva uma solução própria em Python 3.
4. **Testar:** utilize casos pequenos, casos extremos e testes de mesa.
5. **Comparar:** consulte a resolução comentada somente depois da tentativa.
6. **Revisar:** analise a complexidade e relacione a solução ao conteúdo teórico.
