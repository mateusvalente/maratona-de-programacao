Doubly linked list

Lista duplamente encadeada

Cada nó guarda duas referências: next para o próximo nó e prev para o nó anterior.

None ← prev · next → None

Invariantes das pontas

  • head.prev é None.
  • tail.next é None.
  • Se A.next aponta para B, então B.prev deve apontar para A.
  • Na lista vazia, head e tail são None.

Vantagem e custo

É possível percorrer nos dois sentidos e remover um nó conhecido sem procurar seu anterior.

Em troca, cada nó ocupa espaço para duas referências e cada alteração deve preservar as ligações dos dois lados.

Laboratório: prev e next

As setas e os campos precisam concordar. Ao remover uma ponta, o novo head ou tail também deve perder a referência para o nó que saiu.

    Removendo um nó conhecido

    Os vizinhos passam a apontar um para o outro. Os casos de head e tail atualizam as referências externas da lista.

    Pythonreconexão dos vizinhos
    class Node:
    def __init__(self, value):
        self.value = value
        self.prev = None
        self.next = None

class DoublyLinkedList:
    def __init__(self):
        self.head = None
        self.tail = None

    def push_front(self, value):
        node = Node(value)
        node.next = self.head

        if self.head is None:
            self.tail = node
        else:
            # O head antigo passa a reconhecer o novo predecessor.
            self.head.prev = node

        self.head = node

    def push_back(self, value):
        node = Node(value)
        node.prev = self.tail

        if self.tail is None:
            self.head = node
        else:
            self.tail.next = node

        self.tail = node

    def remove(self, node):
        # Reconecta o vizinho anterior ou move o head.
        if node.prev is None:
            self.head = node.next
        else:
            node.prev.next = node.next

        # Reconecta o vizinho seguinte ou move o tail.
        if node.next is None:
            self.tail = node.prev
        else:
            node.next.prev = node.prev

        # O nó removido deixa de pertencer à lista.
        node.prev = None
        node.next = None
        return node.value

    def pop_front(self):
        if self.head is None:
            raise IndexError("lista vazia")
        return self.remove(self.head)

    def pop_back(self):
        if self.tail is None:
            raise IndexError("lista vazia")
        return self.remove(self.tail)
