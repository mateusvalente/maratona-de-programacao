# Estruturas de Dados na Prática

Curso independente de estruturas de dados com exemplos e exercícios em C++17.

## Conteúdo

- 31 aulas distribuídas em cinco unidades;
- fundamentos, TAD, memória, ponteiros e Big O;
- vetores, matrizes, strings e lista sequencial;
- listas simples, duplas e circulares;
- pilha, fila, deque e ordenação;
- gerenciamento de memória após a implementação;
- grafos, matriz/lista de adjacência, DFS, BFS e Dijkstra;
- 10 exercícios com enunciado, testes e resolução comentada para download.

## Como abrir

O projeto é estático. Abra `index.html` diretamente ou sirva a pasta com qualquer servidor HTTP local.

O topo e o rodapé são montados pelo shell compartilhado. Para usá-los em qualquer nova página, inclua no `<head>`:

```html
<script src="assets/site-shell.js" defer data-edp-shell></script>
```

Em páginas dentro de subpastas, ajuste apenas o caminho relativo, por exemplo `../assets/site-shell.js`. O script localiza automaticamente a raiz do projeto, carrega `assets/site-shell.css` e monta o cabeçalho, o rodapé e o link de acessibilidade.
