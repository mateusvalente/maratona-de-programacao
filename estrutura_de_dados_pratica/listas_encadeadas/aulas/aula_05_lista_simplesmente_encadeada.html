Singly linked list

Lista simplesmente encadeada

É uma lista implementada por nós em que cada nó guarda um valor e uma referência para o próximo nó.

head → next → None

Componentes

  • Node contém value e next.
  • head referencia o primeiro nó e dá acesso à lista.
  • tail é opcional; quando mantido, referencia o último nó.
  • O next do último nó vale None.

Consequência da ligação única

É possível avançar seguindo next. Não existe um ponteiro direto para voltar ao nó anterior.

Para acessar o elemento da posição i, começamos no head e percorremos até essa posição: O(n) no pior caso.

    Representação em Python

    O ID usado no HTML não precisa existir como campo do objeto. No código real, a própria referência em next conecta os nós.

    PythonNode e LinkedList
    class Node:
    def __init__(self, value):
        self.value = value
        self.next = None

class LinkedList:
    def __init__(self):
        self.head = None
        self.tail = None

    def push_front(self, value):
        node = Node(value)
        # O novo nó aponta para o head antigo.
        node.next = self.head
        self.head = node
        if self.tail is None:
            self.tail = node

    def push_back(self, value):
        node = Node(value)
        if self.tail is None:
            self.head = self.tail = node
            return

        # O tail antigo liga-se ao novo nó, que vira o tail.
        self.tail.next = node
        self.tail = node

    def pop_front(self):
        if self.head is None:
            raise IndexError("lista vazia")

        value = self.head.value
        self.head = self.head.next
        if self.head is None:
            self.tail = None
        return value

    def pop_back(self):
        if self.head is None:
            raise IndexError("lista vazia")

        if self.head is self.tail:
            return self.pop_front()

        # Sem referência para trás, precisamos localizar o penúltimo nó.
        penultimo = self.head
        while penultimo.next is not self.tail:
            penultimo = penultimo.next

        value = self.tail.value
        penultimo.next = None
        self.tail = penultimo
        return value
