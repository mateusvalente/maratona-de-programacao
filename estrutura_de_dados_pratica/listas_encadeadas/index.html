Método de estudo

Como usar este módulo

1. VisualizeUse os controles das aulas para observar como cada operação altera os nós e ponteiros.
2. DesenheAntes de programar, represente head, tail, prev e next no papel.
3. ImplementeResolva cada exercício sem consultar a resposta e teste casos vazios e unitários.
4. CompareAbra a solução comentada e confira invariantes, complexidade e gerenciamento de memória.
